# Compare Studio

เว็บแอปสำหรับเปรียบเทียบไฟล์ทีละคู่หลายรายการในครั้งเดียว รองรับการจับคู่ไฟล์เอง หรือเลือกโฟลเดอร์สองฝั่งจากเครื่องผู้ใช้เพื่อจับคู่ตามตำแหน่งและชื่อไฟล์ภายในโฟลเดอร์

## เริ่มใช้งาน

ต้องมี Python 3.12+ และ Tesseract OCR ในเครื่อง

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

เปิด `http://127.0.0.1:8000` ในเบราว์เซอร์ รองรับ TXT และไฟล์ข้อความ UTF-8 หลายชนิด, PDF ที่มีข้อความ, DOCX, XLSX และ PNG/JPEG/WebP/BMP/GIF/TIFF จำกัด 20 MB ต่อไฟล์ และข้อความที่ดึงได้ 200,000 ตัวอักษรต่อไฟล์

แอปอ่านไฟล์ในหน่วยความจำระหว่างคำขอและไม่บันทึกไฟล์ที่อัปโหลดไว้ถาวร โหมดโฟลเดอร์ใช้ตัวเลือกโฟลเดอร์ของเบราว์เซอร์ จึงเลือกโฟลเดอร์จากเครื่องผู้ใช้ได้โดยไม่ต้องเปิดสิทธิ์อ่าน path ของเซิร์ฟเวอร์

เอกสารเทียบจากข้อความที่ดึงได้ตามลำดับ ไม่เทียบรูป ตารางที่ฝังหรือรูปแบบหน้าใน PDF/DOCX/XLSX ส่วนรูปสองรูปเทียบพิกเซลหลังปรับทิศทาง EXIF; ข้อความในรูปอ่านด้วย Tesseract OCR หากต้องการ OCR ภาษาไทย ให้เพิ่ม `tha.traineddata` ในโฟลเดอร์ `.local/tessdata/` พร้อม `eng.traineddata` ข้อความที่ OCR อ่านตรงกันจะรายงานแยกเป็น “ตรงกันตาม OCR” เพราะ OCR ไม่รับประกันว่าอ่านครบทุกตัวอักษร เอกสารที่ดึงข้อความไม่ได้จะรายงาน “ยังสรุปไม่ได้”

ใช้ HTTPS/TLS และ checksum สำหรับติดตั้งข้อมูลภาษาไทยตามคำสั่งตั้งค่าสภาพแวดล้อมที่บันทึกไว้ใน Cloud Environment การอัปโหลดจำนวนมากประมวลผลพร้อมกันสูงสุด 3 คู่

## เผยแพร่เพื่อเปิดจากมือถือ

มี `Dockerfile` สำหรับบริการโฮสต์ที่รัน Docker และ `render.yaml` สำหรับ Render Blueprint แอปฟังพอร์ตจากตัวแปร `PORT` และมี health check ที่ `/api/health` เมื่อเชื่อม repository กับโฮสต์และ deploy สำเร็จ โฮสต์จะให้ HTTPS URL สำหรับเปิดจากเครือข่ายอื่น การรันบน cloud development environment เพียงอย่างเดียวไม่ได้สร้าง URL สาธารณะ
