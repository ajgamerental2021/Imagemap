# Compare Studio

เว็บแอปสำหรับเปรียบเทียบไฟล์ทีละคู่หลายรายการในครั้งเดียว และสร้างเอกสารจากข้อมูล keyword ในหลายไฟล์ รองรับการจับคู่ไฟล์เอง การอัปโหลดไฟล์จากสองโฟลเดอร์ และการอ่าน path โฟลเดอร์โดยตรงเมื่อรันเซิร์ฟเวอร์บนเครื่องเดียวกับไฟล์

## เริ่มใช้งาน

ต้องมี Python 3.12+ และ Tesseract OCR ในเครื่อง

บน Mac ที่ใช้ Homebrew ติดตั้งด้วย `brew install python@3.12 tesseract tesseract-lang` หาก `python3` ยังเป็นรุ่นเก่า ให้ใช้ `python3.12 -m venv .venv` ในคำสั่งด้านล่าง

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

เปิด `http://127.0.0.1:8000` ในเบราว์เซอร์ รองรับ TXT และไฟล์ข้อความ UTF-8 หลายชนิด, PDF ที่มีข้อความ, DOCX, Excel (.xls, .xlsx, .xlsm, .xlsb) และ PNG/JPEG/WebP/AVIF/BMP/GIF/TIFF จำกัด 20 MB ต่อไฟล์ และข้อความที่ดึงได้ 200,000 ตัวอักษรต่อไฟล์ เลือกไฟล์เดี่ยวจากโหมด “จับคู่ไฟล์เอง”; ถ้าจะเลือกหลายไฟล์ให้ใช้ปุ่ม “เลือกหลายไฟล์” ในโหมดถัดไป ส่วนปุ่ม “เลือกโฟลเดอร์” รับโฟลเดอร์เท่านั้น หากหน้าต่างเลือกไฟล์ของเบราว์เซอร์ใช้ไม่ได้ สามารถลากไฟล์จาก Finder มาวางในช่องของแต่ละฝั่งได้

แอปอ่านไฟล์ในหน่วยความจำระหว่างคำขอและไม่บันทึกไฟล์ที่อัปโหลดไว้ถาวร โหมด **เลือกไฟล์จาก 2 โฟลเดอร์** ใช้ตัวเลือกโฟลเดอร์ของเบราว์เซอร์และส่งไฟล์ให้เซิร์ฟเวอร์ หากต้องการให้เว็บอ่านไฟล์จากโฟลเดอร์โดยตรงโดยไม่อัปโหลด ให้รันเซิร์ฟเวอร์บน Mac/เครื่องที่เก็บไฟล์ด้วยคำสั่งนี้และเลือกแท็บ **อ่านโฟลเดอร์บนเครื่อง**:

```bash
LOCAL_FOLDER_ACCESS=1 .venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

บน Mac ที่รันเซิร์ฟเวอร์เอง กด **เลือกโฟลเดอร์** เพื่อเปิดหน้าต่าง Finder แล้วเลือกสองโฟลเดอร์ หรือใส่ path เต็ม เช่น `/Users/yourname/Documents/original` และ `/Users/yourname/Documents/revised` ระบบจับคู่ไฟล์ตาม path ย่อยและชื่อไฟล์ที่ตรงกัน บน Linux ใช้การใส่ path ด้วยมือ โหมดนี้ถูกปิดโดยค่าเริ่มต้นและเปิดได้เฉพาะคำขอจาก loopback บนเครื่องที่รันเซิร์ฟเวอร์ **Render อ่านโฟลเดอร์บน Mac โดยตรงไม่ได้** เพราะไฟล์อยู่คนละเครื่อง ให้ใช้โหมดอัปโหลดบน Render

Excel เทียบค่ารายเซลล์พร้อมชื่อชีตและตำแหน่ง เช่น `Orders!B2` หน้าเว็บแสดง 500 ตำแหน่งแรกและดาวน์โหลดรายงาน CSV ที่มีรายการทุกเซลล์ที่ต่างได้ เอกสารชนิดอื่นเทียบข้อความที่ดึงได้ตามลำดับ แสดงตัวอย่างตำแหน่งบรรทัด/คอลัมน์และดาวน์โหลด CSV ความต่างรายบรรทัด รูปสองรูปเทียบพิกเซลหลังปรับทิศทาง EXIF และแสดงกรอบบริเวณต่าง; ข้อความในรูปอ่านด้วย Tesseract OCR ผลลัพธ์ไม่ตรวจรูป ตารางที่ฝัง หรือรูปแบบหน้าใน PDF/DOCX และข้อความ OCR อาจคลาดเคลื่อน ข้อความที่ OCR อ่านตรงกันจะรายงานแยกเป็น “ตรงกันตาม OCR” เอกสารที่ดึงข้อความไม่ได้จะรายงาน “ยังสรุปไม่ได้”

## สร้างเอกสารจากข้อมูลหลายไฟล์

ในส่วน **สร้างเอกสารจากข้อมูลหลายไฟล์** ใส่ keyword บรรทัดละคำ เลือกไฟล์ข้อมูลได้หลายไฟล์ หรือระบุ path โฟลเดอร์ในโหมด local ระบบแสดงค่าที่พบทั้งหมดพร้อมไฟล์/ตำแหน่งให้แก้ก่อนใช้ ออกแบบ template ในหน้าเว็บด้วยบล็อกหัวข้อ ข้อความ ช่องข้อมูล เส้นคั่น ปรับสีและลำดับ แล้วส่งออก DOCX, XLSX หรือ PDF ได้ อีกทางหนึ่งอัปโหลดไฟล์ template DOCX/XLSX/XLSM ที่มี `{{keyword}}` หรือ PDF แบบฟอร์มที่ตั้งชื่อช่องเป็น keyword อ่าน [คู่มือสร้าง template](docs/TEMPLATE_GUIDE.md) สำหรับตัวอย่างและข้อจำกัด

ใช้ HTTPS/TLS และ checksum สำหรับติดตั้งข้อมูลภาษาไทยตามคำสั่งตั้งค่าสภาพแวดล้อมที่บันทึกไว้ใน Cloud Environment การอัปโหลดจำนวนมากประมวลผลพร้อมกันสูงสุด 3 คู่

ทดสอบด้วย `.venv/bin/python -m unittest discover -s tests -v` สำหรับผู้ช่วย AI จากแชทอื่นมี [ไฟล์ส่งต่องาน](AGENTS.md)

## เผยแพร่เพื่อเปิดจากมือถือ

มี `Dockerfile` สำหรับบริการโฮสต์ที่รัน Docker และ `render.yaml` สำหรับ Render Blueprint แอปฟังพอร์ตจากตัวแปร `PORT` และมี health check ที่ `/api/health` เมื่อเชื่อม repository กับโฮสต์และ deploy สำเร็จ โฮสต์จะให้ HTTPS URL สำหรับเปิดจากเครือข่ายอื่น การรันบน cloud development environment เพียงอย่างเดียวไม่ได้สร้าง URL สาธารณะ

ขั้นตอนบน Render: สมัครหรือเข้าสู่ระบบ Render, เลือก **New → Web Service**, เชื่อม GitHub repository `ajgamerental2021/Imagemap`, เลือก branch `compare-studio-deploy`, ตั้ง runtime เป็น **Docker** และ plan เป็น **Free**, จากนั้นกด **Deploy Web Service** ไม่ต้องตั้ง build/start command หรือ environment variable เพิ่ม Dockerfile จะเปิดแอปบนพอร์ตที่ Render กำหนด เมื่อสถานะเป็น Live ให้เปิด HTTPS URL ที่ Render แสดงและลองเลือกไฟล์หรือวางไฟล์จากเครื่องของคุณ
