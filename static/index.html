คู่เปรียบเทียบเลือกไฟล์ด้านซ้ายและขวาของแต่ละรายการ เช่น Excel ↔ Excel หรือ Excel ↔ รูป
จับคู่หลายไฟล์โหมดนี้เบราว์เซอร์จะส่งไฟล์ที่เลือกให้เซิร์ฟเวอร์ · ระบบจับคู่ตาม path หรือชื่อไฟล์

เลือกข้อมูลทั้งสองฝั่งเพื่อดูรายการที่จับคู่ได้ · ปุ่ม “เลือกโฟลเดอร์” ต้องเลือกโฟลเดอร์ ไม่สามารถเลือกไฟล์เดี่ยวได้

อ่านจาก path บนเครื่องที่รันเซิร์ฟเวอร์ไม่ส่งไฟล์ผ่านเบราว์เซอร์ · ใช้ได้เมื่อรันแอปบน Mac และเปิด LOCAL_FOLDER_ACCESS=1 เท่านั้น

วาง path ของสองโฟลเดอร์ แล้วกดเริ่มเปรียบเทียบ · ใน Finder ใช้ Option+Command+C เพื่อคัดลอก path

03 / GENERATE

สร้างเอกสารจากข้อมูลหลายไฟล์

ข้อมูลอยู่ในหน่วยความจำระหว่างใช้งานหน้านี้

1. ระบุ keyword และแหล่งข้อมูล

ใส่ชื่อข้อมูลที่ต้องค้นหา บรรทัดละหนึ่งคำ เช่น ชื่อลูกค้า หรือ เลขที่ใบสั่งซื้อ ระบบดึงค่าที่อยู่หลัง :, = หรือในเซลล์ขวา/ล่างของ Excel

เลือกไฟล์หรือโฟลเดอร์ และกำหนด keyword ก่อนเริ่ม

2. เลือก template

วาง {{keyword}} ใน Word/Excel หรือสร้าง PDF แบบฟอร์มที่ชื่อช่องตรงกับ keyword ใช้ {{keyword:first}}, {{keyword:last}}, {{keyword:count}} ได้ใน Word/Excel

ระบบจะรวมทุกค่าที่พบภายใต้ keyword เดียวกันตามลำดับไฟล์
