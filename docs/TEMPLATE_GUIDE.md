# คู่มือสร้างเอกสารจาก template

## เตรียมข้อมูลต้นทาง

กำหนด keyword บรรทัดละหนึ่งคำในหน้าเว็บ เช่น `ชื่อลูกค้า`, `เลขที่ใบสั่งซื้อ`, `ยอดรวม` จากนั้นเลือกไฟล์ข้อมูลได้หลายไฟล์ หรือระบุ path โฟลเดอร์เมื่อรันแอปบนเครื่องเดียวกับโฟลเดอร์และเปิด `LOCAL_FOLDER_ACCESS=1` ระบบอ่านไฟล์ทีละไฟล์โดยจำกัดงานพร้อมกัน 3 ไฟล์ ไม่มีเพดานจำนวนไฟล์ที่เลือกในตัวแอป แต่แต่ละไฟล์จำกัด 20 MB และหน่วยความจำ/เวลาใช้งานขึ้นกับเครื่องหรือโฮสต์

รูปแบบข้อมูลที่อ่านได้:

- ข้อความ, Word หรือ PDF ที่มีข้อความ: `ชื่อลูกค้า: สมชาย`, `ชื่อลูกค้า = สมชาย` หรือชื่อ keyword อยู่บรรทัดหนึ่งและค่าอยู่บรรทัดถัดไป
- Excel: เซลล์ `A1` เป็น `ชื่อลูกค้า` และ `B1` เป็น `สมชาย`; ถ้าเซลล์ขวาว่างให้อ่านเซลล์ด้านล่าง หรือใส่ `ชื่อลูกค้า: สมชาย` ในเซลล์เดียว
- รูปภาพ: อ่านข้อความด้วย OCR ก่อนใช้กฎข้อความ ควรตรวจค่า OCR ในหน้าเว็บก่อนสร้างเอกสาร

ค่าที่พบทั้งหมดจากทุกไฟล์ภายใต้ keyword เดียวกันจะถูกรวมตามลำดับไฟล์ และแสดงชื่อไฟล์กับตำแหน่งที่พบ แก้ค่าในหน้าเว็บได้ก่อนสร้างผลลัพธ์ ระบบไม่เดาความหมายของคำที่ไม่ได้ตั้งเป็น keyword และไม่สามารถอ่านข้อความจาก PDF สแกนที่ไม่มี OCR สำเร็จ

## ออกแบบ template บนเว็บ

เลือก **ออกแบบบนเว็บ** ตั้งชื่อเอกสาร สีหลัก และขนาดตัวอักษร จากนั้นเพิ่มบล็อกหัวข้อ ข้อความ ช่องข้อมูล หรือเส้นคั่น เลื่อนบล็อกขึ้นลงได้ วาง `{{ชื่อลูกค้า}}` หรือ keyword อื่นในช่องข้อความ ตัวอย่างจะแสดงค่าที่ดึงมา ส่งออกเป็น DOCX, XLSX หรือ PDF ได้ และบันทึกแบบเป็น JSON เพื่อเปิดแก้ภายหลังได้

ตัวเลือก placeholder:

| ข้อความใน template | ผลลัพธ์ |
| --- | --- |
| `{{ชื่อลูกค้า}}` | ทุกค่าที่พบ คั่นด้วยบรรทัดใหม่ |
| `{{ชื่อลูกค้า:first}}` | ค่าแรก |
| `{{ชื่อลูกค้า:last}}` | ค่าสุดท้าย |
| `{{ชื่อลูกค้า:count}}` | จำนวนค่าที่พบ |

หากไม่มีค่าของ keyword นั้น placeholder จะคงอยู่ในผลลัพธ์เพื่อให้เห็นว่าต้องแก้ข้อมูล แนะนำให้ตรวจตัวอย่างและรายการค่าก่อนดาวน์โหลด

## ใช้ไฟล์ template ที่เตรียมเอง

- **Word `.docx`**: พิมพ์ placeholder ในข้อความ ย่อหน้า ตาราง หรือหัว/ท้ายกระดาษ เช่น `เรียน {{ชื่อลูกค้า:first}}` จัดรูปแบบเอกสารใน Word ตามต้องการ ระบบพยายามรักษาการจัดรูปแบบเดิม รวมถึง placeholder ที่ Word แยกเป็นหลาย run
- **Excel `.xlsx` / `.xlsm`**: พิมพ์ placeholder ในเซลล์ข้อความ เช่น `{{ยอดรวม}}` ระบบแทนค่าในเซลล์ทุกชีต โดยเก็บรูปแบบเซลล์และ macro ของ `.xlsm` เท่าที่ openpyxl รองรับ สูตร Excel ที่เป็นสูตรอยู่เดิมจะไม่ได้คำนวณใหม่บนเซิร์ฟเวอร์
- **PDF `.pdf`**: สร้าง *fillable PDF form* แล้วตั้ง **ชื่อช่องฟอร์ม** เป็น keyword เช่น `ชื่อลูกค้า` หรือ `ยอดรวม` ระบบกรอกค่าในช่องนั้น หากคาดว่าจะมีหลายค่า ให้ตั้งช่องเป็น multiline และเผื่อพื้นที่ให้พอ หากมีภาษาไทย ต้องใช้ฟอนต์ของฟอร์มที่แสดงภาษาไทยได้ PDF ธรรมดาที่มีเพียงข้อความ `{{keyword}}` ไม่สามารถแทนที่โดยคง layout ได้ ให้ใช้ตัวออกแบบบนเว็บเพื่อสร้าง PDF หรือแปลงเอกสาร Word เป็น PDF หลังสร้าง

ไฟล์ template ที่อัปโหลดต้องมี placeholder หรือช่องฟอร์มที่ตรงกับ keyword ที่มีข้อมูล มิฉะนั้นระบบจะแจ้งข้อผิดพลาด แหล่งข้อมูลสามารถเป็น Excel, Word, PDF, ข้อความ หรือรูปภาพตามชนิดไฟล์ที่แอปรองรับ แม้ชนิด template จะต่างจากชนิดไฟล์ข้อมูล
